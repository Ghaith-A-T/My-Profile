# My-Profile
Personal Profile Website

## Overview
This project is a simple personal profile website built using HTML and CSS. It introduces basic information about me, including my background, skills, hobbies, and contact information. The website features a modern dark theme with an AI-inspired background.

## Features
- Responsive profile page
- Dark theme design
- AI-inspired background
- Skills section
- Hobbies section
- Contact information
- Built using only HTML and CSS

## Technologies Used
- HTML5
- CSS3

## Project Structure

```
Project/
│── index.html
│── style.css
│── ai-background.png
│── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html** or open it with Live Server in Visual Studio Code.
